# Anatomia: прототип

Это первый рабочий прототип локального приложения для анатомических карточек.

## Что уже работает
- создание и редактирование наборов;
- создание карточек с одним изображением, русским и латинским названиями;
- удаление карточек;
- режим изучения со скрытым/открываемым латинским названием;
- независимые кнопки «Знаю» и «Не знаю»;
- сохранение истории оценок отдельно от карточек;
- светлая и тёмная темы;
- экспорт набора в `.anat` и импорт такого файла;
- резервный экспорт всех наборов;
- локальное хранение в IndexedDB.

## Запуск на компьютере
Для IndexedDB и Service Worker лучше запускать проект через локальный HTTP-сервер, а не открывать `index.html` двойным щелчком.

Если установлен Python, откройте терминал в папке проекта и выполните:

    python -m http.server 8000

Затем откройте в браузере:

    http://localhost:8000

## Установка на Android
Для установки PWA нужен HTTPS-сайт. Этот архив пока является исходным проектом, а не опубликованным приложением. Разместите файлы на статическом хостинге с HTTPS, откройте адрес в Chrome на Android и выберите «Установить приложение» или «Добавить на главный экран».

## Важные ограничения прототипа
- Данные хранятся только в текущем браузере и на текущем устройстве.
- Очистка данных браузера может удалить карточки. Регулярно используйте экспорт резервной копии.
- Формат `.anat` в этой версии представляет собой JSON-файл с вложенными изображениями в Base64. Расширение `.anat` используется для удобства обмена.
- Пока нет синхронизации между устройствами, интервального повторения, поиска, категорий и объединения наборов.
- Статистика показывает количество оценок, а не полноценную систему освоения терминов.
