# Mimir

Локальное приложение для изучения анатомических структур с помощью карточек.

## Возможности версии 0.4.3

- создание и редактирование наборов;
- создание карточек с одним изображением, русским и латинским названиями;
- удаление отдельных карточек;
- удаление набора вместе со всеми его карточками и связанной историей оценок;
- единый экран повторения с выбором одного или нескольких наборов;
- четыре режима: повторение, сопоставление пар, подбор названия и подбор перевода;
- игровые режимы: сопоставление пар, подбор названия и подбор перевода;
- режим изучения со скрытым/открываемым латинским названием;
- независимые кнопки «Знаю» и «Не знаю»;
- сохранение истории оценок отдельно от карточек;
- светлая и тёмная темы;
- экспорт набора в `.anat` и импорт такого файла;
- резервный экспорт всех наборов;
- локальное хранение в IndexedDB;
- управление изображением в режиме изучения: вписывание, заполнение области, увеличение и перемещение.

## Запуск на компьютере

Для IndexedDB и Service Worker лучше запускать проект через локальный HTTP-сервер, а не открывать `index.html` двойным щелчком.

Если установлен Python, откройте терминал в папке проекта и выполните:

    python -m http.server 8000

Затем откройте в браузере:

    http://localhost:8000

## Установка как PWA

Для установки приложения нужен HTTPS-сайт. Разместите файлы на статическом хостинге с HTTPS, откройте адрес в Chrome на Android и выберите установку приложения.

Манифест ожидает иконку по пути `icons/icon.svg`. Если вы переносите эту версию в уже существующий репозиторий Mimir, сохраните его текущую папку `icons` с вашей иконкой.

## Хранение данных и резервные копии

- Данные хранятся только в текущем браузере и на текущем устройстве.
- Очистка данных браузера может удалить карточки. Регулярно используйте экспорт резервной копии.
- Формат `.anat` в этой версии представляет собой JSON-файл с вложенными изображениями в Base64.
- Экспорт набора включает карточки и изображения, но не историю оценок.
- Синхронизации между устройствами пока нет.

## Обновление с предыдущей версии

Внутреннее имя базы IndexedDB сохранено прежним, поэтому при обновлении на том же адресе сайта существующие наборы и карточки должны остаться доступны. Не очищайте данные сайта и не меняйте адрес публикации.

При обновлении Service Worker используется новый ключ кэша `mimir-shell-v7`, чтобы браузер загрузил обновлённые файлы приложения.

## Изменения

### Версия 0.4.3
- Нижняя навигация упрощена: оставлен один пункт «Наборы» вместо дублирующих «Главная» и «Наборы».
- Смешанное изучение и игровые режимы объединены на экране «Начать повторение».
- Добавлены четыре отдельные кнопки выбора режима.
- Убрана кнопка начала изучения из отдельного набора: один набор теперь выбирается на общем экране повторения.
- В шапке вместо буквы отображается SVG-иконка Mimir.
- Уточнены отступы, состояния кнопок и адаптивная раскладка.

### Версия 0.4.2
- Добавлено смешанное изучение карточек из выбранных наборов без копирования карточек.
- Добавлены три игровых режима: сопоставление русских и латинских названий, подбор названия по изображению и подбор перевода.
- Игры используют существующие карточки и не записывают результаты в обычную историю оценок.

### Версия 0.4.1
- Приложение переименовано в Mimir.
- Добавлено безопасное удаление набора одной транзакцией IndexedDB. Вместе с набором удаляются только его карточки и связанные записи истории.
- Имя файла резервной копии всех наборов изменено на `mimir-backup.anat`.

### Версия 0.4
- Исправлено управление изображением в режиме изучения: «Вписать целиком» сбрасывает масштаб и перемещение и показывает изображение целиком.
- Добавлено перетаскивание изображения мышью или пальцем.
- Диапазон увеличения расширен до 300%; перемещение сохраняется при изменении масштаба и сбрасывается при переходе к следующей карточке.

## Технические примечания

Внутреннее имя базы данных IndexedDB (`anatomia-db`), ключ настройки темы и идентификаторы формата `.anat` сохранены для совместимости с уже созданными данными и резервными копиями. Эти строки не являются отображаемым названием приложения.
